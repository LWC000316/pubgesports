# 중간 보고서 14: WWCD.lol 벤치마킹 및 데이터 파이프라인 아키텍처 역공학 분석

## 1. 개요 및 목적
사용자 요청에 따라 배틀그라운드 eSports 전문 분석 웹사이트인 `https://wwcd.lol`의 프론트엔드 번들 및 네트워크 엔드포인트를 역공학 분석하여 UI/UX 설계 철학과 데이터 수집 및 제공 아키텍처를 과학적이고 투명하게 규명하였습니다.

## 2. UI/UX 구성 및 벤치마킹 포인트

### 1) 핵심 가치 제안
• 슬로건: "Analyze, Review, Win | WWCD.lol"
• 단순 선수 세팅 뷰어가 아닌, 경기 분석관 및 코치, 팬들을 위한 실전 경기 복기 및 토너먼트 종합 분석 플랫폼을 지향합니다.

### 2) 화면 구성 및 메뉴 체계
• 2D 매치 리플레이 (2D Replay): 16개 팀 64명 선수의 실시간 위치, 이동 경로, 자기장 축소, 교전 킬로그를 지도 상에서 인터랙티브하게 재생
• 종합 리더보드 (Combined Stats): 스테이지 진행 상태(live, ongoing, upcoming, ended) 자동 판정 및 치킨 수, 킬 수, 딜량 실시간 계산 순위표
• PGC 시뮬레이터 (Road to PGC Simulator): 남은 경기 순위에 따른 포인트 합산 및 세계대회 진출 가능성 시뮬레이션
• 선수 커리어 요약 (Player Career Summary): 대회 등급별(PGC, PGS, Regional) 누적 성적 및 개인 기록

### 3) 디자인 시스템 특징
• 짙은 다크 네이비(`#161a26`) 바탕에 고대비 텍스트 배치
• 불필요한 장식 배너를 완전히 배제하고 오직 데이터 테이블과 시각화 맵 중심으로 설계된 군더더기 없는 고밀도 대시보드

## 3. 데이터 파이프라인 및 수집 방식 역공학 분석

### 1) 데이터 저장소 아키텍처
• 백엔드 인프라: Vercel 배포 및 Supabase(PostgreSQL 기반 BaaS) 활용
• 프로젝트 식별: `https://sqsouczuiycvtjnfztqs.supabase.co`
• 스토리지 버킷: Supabase Storage 내 `telemetry` 버킷 운용

### 2) 데이터 처리 파이프라인
• 공식 PUBG API의 텔레메트리 데이터 활용
• 수십~수백 MB의 원본 Telemetry 로그를 1초 단위 위치(`frames`), 자기장(`zones`), 킬(`kills`), 피해 이벤트(`damageEvents`) 등으로 전처리하여 수 MB 단위의 경량 JSON으로 압축 저장
• 클라이언트 웹 브라우저가 해당 매치 JSON을 직접 다운로드한 뒤 2D 캔버스 엔진(`renderer.js`)으로 재생 및 즉석 통계 집계

### 3) 특수 관리 도구 (OCR 지원)
• 공식 API 데이터 제공 전 또는 방송 화면 기반 빠른 집계를 위해 브라우저 OCR 엔진(`tesseract.js`)을 탑재한 관리자 도구 운용

## 4. 본 프로젝트(PUBG PRO VAULT)에의 시사점 및 적용 방안
• 단순한 더미 프로필 열람을 넘어, 실제 공식 경기 텔레메트리 기반 2D 매치 리플레이 또는 검증된 실제 경기 스탯 연동 기능이 사용자에게 압도적인 가치를 제공합니다.
• 텍스트 배너 위주의 복잡한 화면 대신, 깔끔한 다크 테마 리더보드와 인터랙티브 시각화 요소를 결합하는 방향으로 UI/UX를 재정의하는 것이 타당합니다.
