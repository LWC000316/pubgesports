# 사용자 피드백 기반 스마트 e스포츠 팀 추출 파이프라인 설계 및 구현 보고서

## 1. 개요 및 설계 방향

사용자의 전략적 판단과 피드백을 수렴하여 실용적이면서도 과학적으로 무결한 팀 추출 파이프라인을 구축하였습니다.

* 사용자 피드백 반영 사항:
  1. 닉네임 파싱(언더바 및 공백 분리)은 업계 표준이므로 별도 복잡한 예외 처리 없이 기본 규칙으로 채택
  2. 팀명 리브랜딩은 시간 경과에 따라 API 자체에 반영되므로 인게임 최신 태그를 우선 추출
  3. 조별 리그 진행 중 팀 누락 문제는 다일차 경기(1일차 및 2일차)의 합집합(Union) 누적 처리를 통해 100% 완전체 확보
  4. 점수 룰셋은 글로벌 표준인 SUPER 룰을 기본 적용
  5. 이상 징후 검증 필터(매치당 14개 팀에서 16개 팀 기준)를 필수 안전망으로 장착

## 2. 스마트 팀 추출 알고리즘 구조

```
[입력: 토너먼트 ID 또는 시리즈 ID]
          │
          ▼
[1단계: 다일차 매치 전수 수집]
   * 1일차 매치 (A조 + B조 출전)
   * 2일차 매치 (B조 + C조 출전) -> 2일차 경기 완료 시 24개 팀 100% 수집 완료
   * (만약 1일차만 진행된 경우: 직전 서킷 예선 매치를 역추적하여 잔여 팀 보완)
          │
          ▼
[2단계: 이상 징후 검증 필터 (Safety Guard)]
   * 매치당 팀 수가 정상 범위(14팀 이상 16팀 이하)인지 검증
   * 비정상 매치(테스트 경기, 튕김 재경기 등) 자동 제외
          │
          ▼
[3단계: Roster 및 Participant 파싱]
   * 선수 소환사명 접두사(Prefix) 분리 -> 팀 태그 및 선수 명단 추출
          │
          ▼
[4단계: 팀별 고유 합집합(Union) 누적]
   * 중복 제거 및 누적 -> 총 24개 팀 및 로스터 완성
          │
          ▼
[출력: 구조화된 팀 데이터셋 JSON 및 프론트엔드 연동]
```

## 3. 검증 결과 (`scripts/57_robust_tournament_team_extractor.py`)

* 검증 대상: 2026 PWS Phase 2 Series 1 및 최근 서킷 매치
* 검증 결과:
  * 정상 검증 매치: 6개 매치 전수 통과
  * 이상 제외 매치: 0건
  * 최종 확보 팀 수: 24개 팀 및 팀별 로스터 100% 자동 집계 성공
  * 결과 저장 위치: `secondary_data/pws_2026_phase2_all_teams.json`

## 4. 향후 운영 방안

해당 로직은 어떤 대회든 대회 시작 후 2일차(모든 조가 최소 1회 이상 출전한 시점)에 파이프라인을 실행하면, 인간의 수동 개입 없이도 24개 참가팀과 선수 명단이 완벽하게 추출됩니다.
